# Historical documentation

Archived material preserves original designs, test scenarios and dated findings. It is not an active roadmap, current setup guidance or evidence of present release readiness. Start with the [current documentation](../README.md), [roadmap](../product/Roadmap.md) and [security status](../security/README.md).

On 2026-09-22, phase/brainstorm plans and older test plans were moved here; the old OpenClaw design and threat model were preserved before replacement. Historical audit statuses remain dated. The duplicate Telegram plan, superseded SPS setup guide and pre-HPKE essay were removed. Existing implementations and tests were retained.
