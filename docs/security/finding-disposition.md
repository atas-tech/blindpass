| N-01 | Medium | `fixed` (2026-10-06, local tests only) | `POST /api/v3/admin/bootstrap` hashes the supplied password with Argon2 **before** the bootstrap token is checked, synchronously inside the async handler, with no throttle and no use of `login_hash_slots` or `spawn_blocking` (`crates/blindpass-controller/src/routes/admin.rs:74`; contrast `admin_session.rs:178`).
