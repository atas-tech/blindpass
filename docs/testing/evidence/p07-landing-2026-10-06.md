## Browser evidence

**Method.** [p07-landing-evidence.mjs](../../../landing/tests/browser/p07-landing-evidence.mjs) serves `landing/dist` from a throwaway loopback HTTP server, then for each viewport uses a fresh browser context with no stored state: loads, scrolls the whole page, records every request, cookie, storage key and console message with a HAR (content omitted); clicks each of the six CTAs in its own fresh context against real `github.com`; clicks every in-page anchor. Chromium 152.0.7977.82 (Arch `/usr/bin/chromium`) through the workspace's existing `@playwright/test` 1.58.2; no dependency added. Viewports 1440×900 and 390×844 (mobile emulation with touch). Raw output: [p07-landing-2026-10-06/](p07-landing-2026-10-06/) (summary JSON, two HARs, two screenshots; the HARs are 26 KB each, contain no bodies and no cookies).

**Limits.** The server is plain HTTP on loopback: it shows what the page itself requests and stores, and nothing about GitHub Pages, TLS, headers or HSTS. There is no consent UI after removal, so the “no consent / rejection / acceptance / withdrawal” legs of P07-I06 do not apply; the one applicable case is a fresh visit. Safari, Firefox and a real phone were not run. GitHub's page loads were not inspected beyond the main-frame navigation.
