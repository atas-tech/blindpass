## Plaintext, persistence and remaining integration

The private URL/code string is consumed by selected provider and, in URL mode,
the client transport. It never appears in safe result or audit fields. The
router holds it during its bounded25s call, additionally limited by the trusted
original kernel-uptime deadline. JavaScript strings have no forensic erasure
guarantee; an arbitrary injected callback may retain copies or continue I/O
after cooperative abort. The URL-mode message is fixed and contains no link.

The ledger sees only operation key, SHA-256 binding fingerprint and safe outcome.
Tests use an atomic in-memory ledger. Production durable reservation, permissions,
crash/restart recovery, expiry/one-use operator authentication and ciphertext
provisioning remain to implement and verify. The protocol function's ledger
contract is not durable-state evidence. Delivered means provider delivery or
URL navigation consent, never confirmed approval, login or provisioning.

The native updated dependency candidates remain pending the separate ADR0007
human review. No Go toolkit or restic/rest-server binary was downloaded or run.
Full P05 acceptance remains open.
